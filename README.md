# TinyML Lab

零依赖单文件 HTML：一个 2→H→H→1 的多层感知机（MLP）在你浏览器里从零训练，实时可视化决策边界的形成。

## 特性

- **纯手写神经网络**：权重初始化、前向传播、反向传播、BCE 损失全部手写，零框架、零依赖、零构建
- **四种经典数据集**：XOR 四角 / 同心圆环 / 双月牙 / 双螺旋
- **实时决策边界**：96×96 概率网格着色，训练中随时暂停观察
- **可调参数**：隐藏层宽度（4/8/16/24）、学习率（0.05–0.5）
- **带动量的批量梯度下降**（β=0.9），双螺旋这种非凸难题也能收敛到 99%+
- **确定性**：固定种子 RNG（mulberry32），同种子同结果，刷新即可复现

## 使用

直接用浏览器打开 `index.html`，点"开始训练"。双螺旋是难度上限——24 宽隐层 + 0.3 学习率 + 耐心。

## 工程质量

- `_smoke.js`：Node 无头自检 40+ 断言——确定性、数据集不变量、**梯度检验（解析 vs 中心差分 < 1e-6）**、XOR 收敛、各数据集准确率、输出值域、边界情况
- `_probe.js`：ASCII 决策图 dump，肉眼核对边界形状（断言全绿 ≠ 结果正确）
